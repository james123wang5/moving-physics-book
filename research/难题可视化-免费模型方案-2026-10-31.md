# 难题可视化：不花 API 钱、靠学生自己的模型能不能做（2026-10-31）

想法：学生把一道物理难题交给 AI，AI 把题目场景还原成 2D 或 3D 动画（能交互最好，视频或动图也行）。每一问配受力、运动、能量变化，讲清答案为什么是这样。题型针对多过程的板块、传送带、电磁感应大题、带电粒子，以及带 2D 题图的选择题。网站方不出模型费，用学生手上的模型。

## 1. 结论

**能做，但不能让 AI 写动画。** 要把活拆开：

- **AI 只做三件事**：判断题目由哪几段过程组成、把数据原样抄出来、把每一问对应到具体的时刻或物理量。这一步输出一份固定格式的 JSON。
- **我们的引擎负责所有物理**：算运动；判断共速、滑离、进出磁场这些转折；画受力和能量。
- **用答案核对**：学生做的练习和真题通常都有答案。引擎算出的数和答案一致，才标"已核验"。

这样，即使模型自己解不对题，只要把条件抄对，结果就对；抄错了，也会被答案拦下。对模型能力的要求，从"做对压轴题，再写对动画代码"降到了"读懂题、抄对数"。

## 2. 为什么不能让免费模型直接写动画

- **没有任何公开测评单独给出各模型在压轴题上的分数。** 2026 年羊城晚报的高考测评只有总分排名：物理类总分 Claude-Opus-4.8 和讯飞星火-X2 并列第一，豆包第 4，DeepSeek V4-Pro 第 6，千问第 7，GLM 末位。
- **难题和带图题会掉分。**
  - PhysReason：难题准确率约 32%。
  - SeePhys Pro：信息越多放在图里，准确率越低。Kimi K2.5 从 52 降到 42，Claude 4.7 Opus 从 74 降到 46.5。100 名中国高中生的成绩是 54–59.5。
- **AI 写的物理动画，能跑不代表对。**
  - SimuScene：10 个模型写物理动画代码，最好的只有 21.5%。
  - MooseBench：修到能运行之后，仍有 39–40% 的物理是错的。
- **老师们的实录**：能找到的成功例子都是简单题，比如小船过河（DeepSeek 改 3 轮）、弹簧、单摆、胡克定律。压轴题只有成品展示，没有过程记录。翻车的例子有：
  - 电表的内外圈刻度放反
  - 弹簧小球越飘越偏
  - 豆包改一个错又冒出一个新错
  - 有人做带电粒子题时，运动方程是自己写好再交给 AI 渲染的

## 3. 方案

### 3.1 AI 输出什么（ProblemSpec JSON）

- `chain`：从固定清单里选过程模块，按顺序排，例如 `[斜面, 板块, 弹簧]`。
- `params`：用国际单位的数值，每个数都附上题目原文，方便学生核对。
- `asks`：每一问一条，格式是 `{问的是什么量（枚举）, 在哪个时刻或事件, 参考答案}`。
- 模型不写公式，也不写各阶段的起止时间。

### 3.2 引擎做什么（我们写一次）

- **每个模块**用解析解，或者用带事件检测的小积分器。
- **摩擦方向**按相对运动判断；静摩擦和滑动摩擦的切换、共速、滑离、到端点，都由引擎判断。
- **模块之间**用出口事件传递末状态。整道题就是一条"过程链"。
- **每一问**对应时间线上的一段，自动加上该问需要的叠加层：受力箭头、v-t 图和面积、能量柱、动量柱。
- **画面**：能用平面讲清就画 2D；带电粒子的螺旋线、磁聚焦这类再上 3D。可以导出视频或动图（浏览器录屏，或者用 manim-web、Motion Canvas）。

### 3.3 核对

- **数对不上时**，先自动排查常见原因：g 取 10 还是 9.8、37°和 53°的近似、方向、单位。
- **还对不上**，生成一段"修复提示"，让学生贴回给 AI 再改，最多 2 轮。
- **再不行**，弹出参数表让学生自己改。
- **没有答案时**，只做守恒自检，并标"未对答案核验"。
- **题型不在清单里**，直接告诉学生"这题暂不支持"。PhysicsOS 也是这么做的。

### 3.4 先做哪些题型

| 顺序 | 题型 | 引擎要处理的事件 |
|---|---|---|
| 1 | 板块、滑块 | 共速、相对滑动、滑离 |
| 2 | 传送带（水平和倾斜） | 共速后重新判断摩擦，划痕长度，摩擦生热 Q = fΔs |
| 3 | 斜面或圆弧接水平面再接弹簧（能量链） | 到端点、最大压缩 |
| 4 | 碰撞 | 速度瞬间改变 |
| 5 | 导体棒单棒加导轨 | 达到终速，电荷量 q = BLx/R |
| 6 | 带电粒子在电场、磁场区域里运动 | 圆弧的入口和出口 |

PhysicsOS 恰好没有板块、传送带这类多过程模型，这正是空白。

## 4. 不花 API 钱的四种办法

1. **复制粘贴中转（双方都零成本）**
   - 网站给出一段提示词，提示词里包含格式说明、清单和两个示例。
   - 学生把提示词和题目一起发给豆包、DeepSeek、元宝的免费 App。DeepSeek 网页版从 2026-09 起能识图。
   - 学生把返回的 JSON 贴回网站，网站宽容地提取内容并校验。
   - 有先例：编程工具 Aider 有同样的复制粘贴模式（4.98 万星）。
2. **学生自带 key，直接从浏览器调用**
   - 已验证这些服务允许浏览器跨域调用：DeepSeek、硅基流动、阿里百炼（DashScope）、OpenRouter。
   - 每题大约：deepseek-flash 0.1–0.2 元，豆包 lite 0.07 元，豆包 turbo 0.4 元。
   - key 只存在学生自己的浏览器里。
3. **免费 API 小模型**：智谱 GLM-4.7-Flash（文本）、GLM-4.6V-Flash（看图）免费。只让它分类、抄数，不让它解题。效果还需要自己做小评测。
4. **共享题库**
   - 一道题核验通过后永久保存，后来的人直接看，不再生成。
   - 常见真题（各省压轴题）可以由你用自己的 Claude Pro 订阅、在 Claude Code 里先批量做出第一批，不另付 API 费。

## 5. 风险

- **免费模型抄条件、对每一问的准确率没有数据**，尤其是看题图的部分，必须自己实测。
- **清单之外的题型做不了。** 要接受"暂不支持"，靠逐步增加模块来扩大覆盖。
- **学生可能看懂动画就以为自己会了。** 可以沿用"先预测、再播放"的环节。
- **大厂动作快**：飞象老师、Gemini 已经在做概念级的交互仿真。但"多过程难题、数值核验、题库"这一块目前没人做。

## 6. 可以借鉴的东西（宽松协议）

- **edulab**（Apache-2.0）：
  - 解题卡六步，先分段、再用 sympy 验算。
  - phys.js 里的受力箭头、斜面、弹簧、带游标的 v-t 图、能量柱。
  - 示例里的模型契约：`{tMax, phases, state(t), forces(t), charts, answers}`。
- **PhysicsOS**（Apache-2.0）：确定性解析器、场景合同、校验器，以及遇到不支持的题型直接拒绝的做法。
- **WorldByCode**（MIT）：严格格式、本地校验、物理检查、修复循环；AI 从不写可执行代码。
- **渲染库**：matter.js、planck.js、three.js（都是 MIT）。
- **注意**：Remotion 的商用授权有限制。

## 7. 建议的下一步：小样实测（先别铺开）

1. 我写板块模型的 ProblemSpec 格式、提示词，以及引擎和渲染的小样。
2. 你挑 5 道带答案的板块真题，用豆包和 DeepSeek 的免费 App 走一遍复制粘贴流程。
3. 统计三件事：条件抄对了几成，答案核对通过了几成，平均要几轮修复。
4. 用这些数字决定：这条路行不行，要不要换成学生自带 key，以及要不要扩到电磁感应。
