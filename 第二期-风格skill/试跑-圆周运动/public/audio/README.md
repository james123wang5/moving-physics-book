# 音效文件

放这里的 mp3 会被 `src/app/sound.js` 自动加载（缺的文件静默跳过）。可以给同一个名字放几个变体：`thud.mp3`、`thud-2.mp3`、`thud-3.mp3`，播放时随机挑一个。

| 文件名 | 用在哪里 | 想要的声音 |
|---|---|---|
| page | 翻页 | 厚纸翻过去的一声 |
| pen | 插图被钢笔画出来（循环，约 3–4 秒） | 钢笔在纸上沙沙地划 |
| tick | 勾预测、点目录、测验作答 | 铅笔打勾 |
| flap | 掀开 / 合上翻盖 | 卡纸翻动 |
| stamp | 挑战完成盖章 | 橡皮章按在纸上 |
| launch | 小球被弹出、炮管发射 | 弹簧“嘣”一下 |
| thud | 小球落地 | 小木球落在木板上 |
| plop | 小球落进桶 | 球掉进铁皮桶 |
| whoosh | 链球甩出 | 短促的风声 |
| grind | 砂轮火花 | 金属打磨 |
