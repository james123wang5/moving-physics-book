## 二、每个跨页的模板

**左页**（从上到下）

1. 节号和标题

- 图注
- 页边手写批注：提示、易错点

## 四、各跨页内容

### 跨页 1 · 曲线运动（对应 5.1）

**教材怎么写的**：用砂轮火星和链球引入。演示一个钢球离开弯道后在纸上留下的印迹，说明速度沿切线。再用割线逐渐逼近切线做数学说明。然后演示磁铁吸引滚动的钢球，得出曲线运动的条件。“做一做”是自制飞镖观察速度方向。

**我们写什么**

- **引言**：物体走弯路时，速度方向一直在变。它在每一刻朝哪个方向走？什么让它拐弯？
- **公式卡**：速度方向 = 轨迹在该点的切线方向；合力与速度不在一条直线上 → 物体做曲线运动
- **关键词**：曲线运动、切线、变速运动、合力
- **装置：冰面上的冰球**
  - 冰球在冰面上滑行，学生拖一支力箭头按在冰球上，可以调方向和大小，冰球的路径跟着弯。
  - 点“撤力”，冰球沿那一刻的切线直线滑出，页面画出切线和速度箭头。
  - 第二个模式：在一段弧线上拖动点 B 向点 A 靠近，割线慢慢转成切线。
- **预测**：冰球正在转弯，力突然撤掉，它接下来会怎样？
  - A 沿原来的弯路继续转
  - B 沿撤力那一刻的切线直线滑出（正确）
  - C 沿半径方向被甩向外侧
- **翻开看**：没有力就没有加速度，速度不再变，冰球走直线。这条直线的方向就是撤力那一刻的速度方向，也就是切线。“甩向外侧”是常见误解。
- **挑战**：只靠拖力箭头，让冰球绕过中间的障碍物滑进球门。
- **你的数据**：速率 v；力与速度的夹角 α；实时显示“在加速 / 在减速 / 速率不变”。
- **进阶**：把合力拆成沿切线和垂直切线两部分。沿切线的部分改变速度大小，垂直切线的部分改变速度方向。轨迹总是夹在速度方向和合力方向之间，并向合力一侧弯。

### 跨页 2 · 运动的合成与分解（对应 5.2）

**教材怎么写的**：用“游泳过河会不会偏”引入。演示红蜡块在玻璃管里匀速上升，同时玻璃管水平匀速移动。建坐标系，写出 x、y 随时间的关系，消去 t 得出轨迹是直线。用勾股定理和正切求合速度的大小和方向。例题比较两人走楼梯和坐扶梯谁先到。思考与讨论问玻璃管匀加速移动时轨迹是否还是直线。

**我们写什么**

- **引言**：一个运动可以拆成两个方向上各自独立的运动；反过来，两个运动也可以合成一个。
- **公式卡**：x = vₓt，y = v_yt；v = √(vₓ² + v_y²)，tanθ = v_y / vₓ
- **关键词**：分运动、合运动、运动的合成、运动的分解
- **装置：小船过河**
  - 3D 河段，可以拖船头方向，调船速和水速。
  - 画出船速、水速、合速度三支箭头和实际航迹。
  - 开关“水流越来越急”：水速随时间增大，航迹变成曲线。
- **预测**：船头始终正对对岸开，水流变急，过河时间会怎样？
  - A 变长
  - B 不变（正确）
  - C 变短
- **翻开看**：过河时间只由垂直河岸方向的分运动决定。水流只把船往下游推，不影响横渡时间。两个分运动各管各的。
- **挑战**：三关。① 用最短时间过河。② 正好到达正对岸。③ 水比船快时，找一种走法，让船在下游靠岸的位置离出发点最近。
- **你的数据**：过河时间 t；靠岸点在下游多少米；合速度的大小和方向。
- **进阶**：
  - 过河的两类极值：最短时间、最短路程。
  - 船速小于水速时，最短路程的几何作法。
  - 岸上收绳拉船靠岸时，船速和绳速的关系（关联速度）。

### 跨页 3 · 实验：探究平抛运动的特点（对应 5.3）

**教材怎么写的**：先定义抛体运动和平抛运动。实验思路是把平抛拆成水平和竖直两个方向。方案一分析频闪照片，方案二先研究竖直方向再研究水平方向。参考案例用小锤击打金属片，让两球同时出发比较落地先后；再用斜槽加可调挡板在复写纸上描出轨迹。拓展学习介绍用超声—红外传感器描轨迹。

**我们写什么**

- **引言**：把平抛拆成水平和竖直两个方向，各自是什么运动？用实验来查。
- **公式卡**：相等时间内 Δx 相等 → 水平方向匀速；从抛出点起相邻 Δy 之比为 1 : 3 : 5 → 竖直方向自由落体；Δy₂ − Δy₁ = gT²
- **关键词**：抛体运动、平抛运动、频闪照相、等时间间隔
- **装置：虚拟实验台**
  - 桌边的发射器把小球水平弹出，同一时刻旁边另一个小球自由下落。
  - 开关 ①“频闪”：每隔 T 留一个残影。
  - 开关 ②“方格背景”。
  - 开关 ③“影子”：小球在地面上的影子（看水平分运动）和在墙上的影子（看竖直分运动）。
  - 频闪点的坐标自动填进数据表。
- **预测**：两个球同一高度、同一时刻出发，一个水平弹出，一个自由落下，谁先落地？
  - A 弹出的
  - B 落下的
  - C 同时（正确）
- **翻开看**：竖直方向上两个球受力一样，竖直初速度都是 0，所以竖直方向的运动完全一样。水平速度不影响下落。
- **挑战**：只用数据表里的数，算出小球被弹出时的速度 v₀，再点“揭晓”核对。
- **你的数据**：数据表，列出 t、x、y、Δx、Δy。
- **进阶**：用 Δy₂ − Δy₁ = gT² 从照片反推闪光周期。照片上第一个点不是抛出点时，看竖直间隔是不是 1 : 3 : 5 来判断。

### 跨页 4 · 平抛运动的规律（对应 5.4 前半）

**教材怎么写的**：用排球水平击出能否过网、不出界引入。从受力出发，推出水平速度不变、竖直速度 gt，用勾股定理和正切求合速度。例题求落地速度方向。再推出两个方向的位移和轨迹方程，说明轨迹是抛物线。第二道例题是无人机水平飞行时释放小球。

**我们写什么**

- **引言**：受力 → 加速度 → 速度 → 位移。用研究直线运动的老办法，在水平和竖直两个方向各走一遍。
- **公式卡**：vₓ = v₀，v_y = gt；x = v₀t，y = ½gt²；轨迹 y = g x² / (2v₀²)
- **关键词**：分速度、分位移、轨迹方程、抛物线
- **装置：抛射台**
  - 从高度可调的平台水平抛出小球，可调 v₀ 和 h。
  - 球飞行时同时显示两个影子：地面上的影子匀速走，墙上的影子加速落。
  - 速度箭头和两个分量实时更新。
  - 拖时间轴可以回放、定格。
- **预测**：同一高度水平抛出，初速度加倍，落地时间会怎样？
  - A 加倍
  - B 不变（正确）
  - C 减半
- **翻开看**：落地时间只由高度决定，t = √(2h/g)。v₀ 只影响水平飞多远。
- **挑战**：调 v₀ 和 h，让球越过一面矮墙，落进墙后的桶里。
- **你的数据**：t、x、y、v、θ 实时代入公式。
- **进阶**：
  - 速度方向角 α 和位移方向角 β 满足 tanα = 2tanβ。
  - 速度的反向延长线经过水平位移的中点。
  - 从斜面上平抛又落回斜面：飞行时间和落点的求法。

### 跨页 5 · 一般的抛体运动（对应 5.4 后半）

**教材怎么写的**：说明斜抛的受力和平抛完全一样，只是初速度要先拆成水平和竖直分量，给出两个分量的表达式。用喷出的水流举例。思考与讨论让学生自己推出斜抛轨迹式，并讨论有空气阻力时炮弹的实际轨迹。

**我们写什么**

- **引言**：斜着扔出去，受力和平抛完全一样，只是初速度要先拆成两个分量。
- **公式卡**：v₀ₓ = v₀cosθ，v₀_y = v₀sinθ；抛出点和落点等高时，射程 R = v₀² sin2θ / g
- **关键词**：斜抛运动、射程、射高、空气阻力
- **装置：投掷场**
  - 可调角度和速度，每扔一次留下一条轨迹，方便对比。
  - 开关“空气阻力”：同一组参数下，画出真实轨迹和理想抛物线对比。
- **预测**：速度大小一样，在平地上往哪个角度扔得最远？
  - A 30°
  - B 45°（正确）
  - C 60°
- **翻开看**：sin2θ 在 45° 时最大。30° 和 60° 的射程相等，两个角互余。
- **挑战**：站在高台上扔，找出扔得最远的角度，看它还是不是 45°。再打开空气阻力找一次。
- **你的数据**：v₀ₓ、v₀_y、飞行时间、射高、射程。
- **进阶**：
  - 抛出点比落点高时，最佳角小于 45°。
  - 有空气阻力时，轨迹上升段平缓、下降段陡，左右不对称，最佳角也变小。
