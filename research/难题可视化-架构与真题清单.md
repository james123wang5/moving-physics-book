## 1. 目标

把高考物理压轴题（多过程、多部件、条件理想化）还原成 2D 或 3D 动画。**按小问逐一演示**：每一问配运动画面、受力、v-t 图、能量变化，以及解题公式和数值是怎么得出来的，让学生真正学会这道题，而不只是在上面玩。

约束：**我们不付任何模型 API 费用。**

## 2. 流程

```
学生上传题目（文字/截图）＋官方答案（有就带）
        │
        ▼
学生自己的 AI（豆包 / DeepSeek / 元宝…，按我们的提示词）
  ├─ 场景 JSON：有哪些部件、怎么摆、怎么连、参数（附原文）、每一问问什么
  └─ 分问解题过程：有官方答案就按官方答案整理（"润色"由学生的 AI 完成）
        │  复制粘贴回网站，或学生自带 key 从浏览器直连
        ▼
我们的系统（纯前端，不调 AI）
  1. 场景预览 → 学生确认条件没读错
  2. 理想物理引擎独立模拟，自动分阶段
  3. 逐个核对解题过程里的数
       ├─ 一致 → "已核验"（有官方答案）或"引擎复核一致"（没有官方答案）
       └─ 不一致 → 标出出错的那一步，生成修复提示，让学生贴回给 AI（最多 2 轮），否则让学生自己改参数表
  4. 按小问播放：动画片段 ＋ 同步高亮的推导步骤 ＋ 叠加层（受力 / v-t / 能量柱 / 动量）
```

## 3. 核心设计

### 3.1 按部件搭积木，不按题型写模板

题目组合千变万化，比如滑块加平抛、多滑块加弹簧、粒子跨多个磁场区，所以只能按部件来写。

- 场景 JSON 只描述部件、几何、连接和初始条件，不写公式。
- 引擎在模拟过程中自己遇到各种组合，不需要我们事先想到每一种。

### 3.2 理想物理引擎（自己写，不用游戏物理引擎）

- **精确计算**：受力不突变时用高精度积分（或解析解）；遇到转折，用事件检测精确求出转折时刻。
- **转折事件**：共速、静摩擦与滑动摩擦的切换（多物体时把可能情况逐一试过）、离开边缘或轨道（弹力为 0）、碰撞（完全非弹性、弹性、恢复系数 e）、弹簧最大压缩、进出场区、锁定与解锁、电荷或电压突变。
- **数值显示**：结果按分数和根号的形式显示（如 4/3 s、2√2 m/s），确实算不出整齐形式时给小数，并注明保留位数。默认 g = 10，37°和 53°按课本取值。
- **画面**：能用 2D 讲清的用 2D；电子在圆筒磁场里的螺旋运动这类用 3D（沿用现有的 three.js 渲染器）。
- **特殊问法**：
  - "求范围、求最值、分情况讨论"：引擎扫描参数找临界值，展示时可拖到临界状态。
  - "第 n 次碰撞、数列递推"：模拟前几次，再显示规律。

### 3.3 讲解

- **两层讲解**：
  - 引擎按阶段自动列出受力分析和方程（牛顿第二定律、动量守恒、能量记账），每一步都代入数值。
  - 学生的 AI 写"老师式"的解题过程，比如整体法、守恒巧解；引擎逐个核对其中的数。
- **配套叠加层**：每一问对应时间线上的一段，自动配上需要的叠加层。
- **先预测再播放**（可选）：防止学生把"看懂动画"误当成"自己会分析"。

### 3.4 小样已经验证过的部分

在对话里做过一道板块题的小样（滑块滑上有地面摩擦的木板，求加速度、共速时间、相对滑动距离、摩擦生热）。引擎算出了：
- 两个阶段的运动
- 受力箭头
- v-t 图，以及两线之间的面积（即相对滑动距离）
- 能量柱
- 分数形式的推导：4/3 s、2/3 m/s、40/9 m
- 共速后"能否一起减速"的判断
- 能量自检：16 J + 2 J = 18 J = ½mv₀²

### 4.1 由此得出的部件清单（引擎第一版要支持的）

- **物体**：质点或小球、滑块、木板、带挡板的滑块、可动轨道或方形物体（内有轨道）、球壳或外壳、轻杆小球、摆锤、导体棒、方形线框、带电粒子。
- **接触面和约束**：水平面、斜面、圆弧或半圆（内侧、外侧、管道）、环形轨道、平台边缘、挡板或天花板或地面；光滑或粗糙，粗糙时允许上滑和下滑摩擦因数不同。
- **连接**：轻弹簧（含锁定和解锁）、轻绳（单绳、双绳）、轻杆（铰接）、粘连。
- **碰撞**：完全非弹性、弹性、恢复系数 e，以及多次碰撞递推。
- **场**：重力、匀强电场、匀强磁场（多区域，含无场区）、随时间和位置变化的磁场、点电荷库仑力、正交电磁场。
- **电路**：导轨、电阻、电容器、电源、开关（多掷）、非线性元件（U = kq）。
- **外部作用**：恒力或推力、受控匀速、突变（电荷、电压、解锁、内部弹射分裂）。

### 4.2 问法清单

- 求某时刻或某事件时的速度、加速度、时间、位移
- 求最大弹性势能、生热、机械能损失
- 求电荷量、电流、电容器电压、终速
- 求坐标、半径、周期、相遇条件
- 求范围、最值，分情况讨论（如 k 的取值范围）
- 求第 n 次碰撞或数列递推（如 λ、多次碰撞）
- 读图或画图：a–F 图、v-t 图
