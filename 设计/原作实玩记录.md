# 原作实玩记录（2026-10-31 新加坡时间凌晨 1 点）

用无头 Chrome + `tools/play.mjs`（能移动、拖动、点击、截图）实际操作了 https://iamtechartist.com/Apps/every-joule/ 。介绍页 https://iamtechartist.com/every-joule/ 只写了“预测—实验—验证、掀翻盖、盖章、插图从纸面立起、能量用发光的颜色流动”，没有技术细节。

## 看到的做法
1. **鼠标划过书页 = 放大镜 + 提示卡**：光标处出现一个圆形液态玻璃放大镜（直径约 95 像素，放大约 2 倍，边缘有彩虹色散）；放大镜上方弹出一张磨砂玻璃卡片，用清晰的 HTML 文字写出光标下那一块的内容：小标题（如 THE EQUATION，红色小号大写）、公式、文字说明；段落就显示整段文字。移开就消失。
2. **页面文字**：原作正文是深色、笔画饱满的衬线字，默认视角下很清楚。我们的中文正文（思源宋体 400）笔画细、发灰。
3. **右页构图**：每课只有 1–2 个**很大的**主装置（U 形轨道+小球、弹簧发射器、落球刻度架、水壶+房子、两台电机吊架、两盏灯），占右页大半高度，周围留白多，互不拥挤。另有一排**能量瓶**（玻璃烧杯放在架子上，下方贴纸签写“0 J”），能量转移时瓶里充入对应颜色的发光液体，旁边还有一根细长的总量条。
4. **交互方式**：直接拖装置本身（“把小球沿轨道拖上去再松手”“把球往后拉压弹簧再松手”“把球提到某个高度再放”），松手后物理过程实时进行，能量瓶同时涨落。第 1 课是“点场景里的每样东西，点亮它的瓶子”（点杯子→热能瓶充橙色液体，杯子周围出现虚线圈）。
5. **发光能量流**：橙色的粗发光带在空中从一个装置流向另一个（效率、加热两课）。
6. 底部开关和我们一样是“图注右边的小字 + 下划线”；控制条按钮和我们一致。

## 我们和原作的差距（要改的）
- A. 放大镜 + 提示卡：我们完全没有。`ui/glass.js` 已支持 zoom>1 的放大镜，只需 UI 跟随鼠标、并让书页排版输出“文字块”（位置 + 标签 + 文字/公式）。
- B. 文字清晰度：正文字重加粗（400→500），页面贴图分辨率 6→9 px/毫米，采样加负的 mip 偏置让缩小时更锐利。
- C. 拥挤与穿模：纸签压在轨迹/装置上、标签互相重叠、物体互相穿插（例如第 4 课桶和楔块、第 5 课射程签和轨迹）。逐课截图检查，挪开或缩小。
- D. 构图（**需要用户拍板**）：原作每屏 1–2 个大装置。我们第 1 课 3 个、第 2 课 2 个、第 4 课 2 个、第 5 课 3 个，都偏小偏挤。方案：每课右页同一时间只摆一个大装置（放大 1.5–2 倍），图注旁加“装置：砂轮 / 链球 / 冰球”这样的开关切换，切换时钢笔重新画出来——既保留“装置多”，每一屏又像原作一样大而疏朗。速度管改成原作式的“仪表架”（烧杯排在架子上、下面贴纸签）。
